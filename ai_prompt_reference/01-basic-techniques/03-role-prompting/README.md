# Role Prompting / Persona

## সংজ্ঞা
মডেলকে একটা নির্দিষ্ট ভূমিকা, দর্শক ও উদ্দেশ্য দিয়ে দেওয়া — যাতে সে সঠিক গভীরতা ও ভাষায় উত্তর দেয়।

## কখন ব্যবহার করবেন
- আউটপুটের টোন বা টেকনিক্যাল গভীরতা নিয়ন্ত্রণ করতে হবে
- একই তথ্য ভিন্ন দর্শকের জন্য লিখতে হবে

## দুর্বল উদাহরণ
```
তুমি একজন সহায়ক আইন বিশেষজ্ঞ। এই চুক্তিটা রিভিউ করো।
```
সমস্যা: "বিশেষজ্ঞ" ট্যাগ লাগালেই আউটপুট বদলায় না।

## শক্তিশালী উদাহরণ
```
তুমি একটা ছোট ব্যবসার হয়ে চুক্তি রিভিউ করছো, যার উকিল রাখার সামর্থ্য নেই।
মালিক আইনি ভাষা বোঝেন না।

কাজ: নিচের চুক্তি থেকে এমন ৩টা ধারা বের করো যেগুলো ভবিষ্যতে
তাঁর টাকা বা মালিকানা হারানোর কারণ হতে পারে।

প্রতিটির জন্য লেখো:
- ধারা নম্বর
- সহজ বাংলায় এর মানে কী
- বাস্তবে কী ক্ষতি হতে পারে
```

## মূল নিয়ম
ভূমিকার চেয়ে **দর্শক ও উদ্দেশ্য** বেশি কাজ করে। "কে পড়বে" আর "কেন পড়বে" — এই দুটো বলে দিলে টোন এমনিতেই ঠিক হয়ে যায়।
