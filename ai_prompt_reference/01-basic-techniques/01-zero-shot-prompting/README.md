# Zero-shot Prompting

## সংজ্ঞা
কোনো উদাহরণ না দিয়ে শুধু নির্দেশনা দিয়ে মডেলকে কাজ করানো। মডেল তার প্রি-ট্রেনিং জ্ঞান থেকেই কাজটা বুঝে নেয়।

## কখন ব্যবহার করবেন
- কাজটা সাধারণ ও সুপরিচিত (সামারি, অনুবাদ, প্রশ্নের উত্তর)
- আউটপুটের ফরম্যাট খুব কড়া নয়
- দ্রুত প্রোটোটাইপ বানাচ্ছেন

## খারাপ উদাহরণ
```
এই রিভিউটা অ্যানালাইজ করো।

"ডেলিভারি দেরি হয়েছে কিন্তু প্রোডাক্টের মান ভালো।"
```
সমস্যা: "অ্যানালাইজ" মানে কী? আউটপুট কেমন হবে? মডেল আন্দাজ করবে।

## ভালো উদাহরণ
```
নিচের কাস্টমার রিভিউটার সেন্টিমেন্ট নির্ণয় করো।
উত্তর দাও শুধু একটি শব্দে: ইতিবাচক, নেতিবাচক, অথবা মিশ্র।

রিভিউ: "ডেলিভারি দেরি হয়েছে কিন্তু প্রোডাক্টের মান ভালো।"
```
আউটপুট: `মিশ্র`

## মূল নিয়ম
Zero-shot ফেল করলে প্রথমেই few-shot-এ যাবেন না — আগে নির্দেশনাটা আরও স্পষ্ট করুন। বেশিরভাগ zero-shot ব্যর্থতা আসলে অস্পষ্ট নির্দেশনার ব্যর্থতা।
