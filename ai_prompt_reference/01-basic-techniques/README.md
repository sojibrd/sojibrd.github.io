# ০১ — বেসিক টেকনিক

প্রতিটা প্রম্পটের ভিত্তি। এই সাতটা ঠিকমতো না করে জটিল কিছুতে যাওয়ার মানে নেই — বেশিরভাগ "মডেল কাজ করছে না" আসলে এই স্তরের সমস্যা।

## এই ক্যাটাগরিতে

| # | টেকনিক | এক লাইনে |
|---|---|---|
| ০১ | [Zero-shot Prompting](01-zero-shot-prompting/) | উদাহরণ ছাড়া শুধু স্পষ্ট নির্দেশনা |
| ০২ | [Few-shot Prompting](02-few-shot-prompting/) | ২–৫টা উদাহরণ দিয়ে প্যাটার্ন শেখানো |
| ০৩ | [Role Prompting](03-role-prompting/) | ভূমিকা, দর্শক ও উদ্দেশ্য ঠিক করে দেওয়া |
| ০৪ | [System Prompt](04-system-prompt/) | পুরো কথোপকথনজুড়ে স্থায়ী নির্দেশনা |
| ০৫ | [Delimiters / XML Tagging](05-delimiters-xml-tagging/) | নির্দেশনা আর ডেটা আলাদা রাখা |
| ০৬ | [Output Formatting](06-output-formatting/) | পার্স করা যায় এমন আউটপুট বেঁধে দেওয়া |
| ০৭ | [Response Prefilling](07-response-prefilling/) | উত্তরের শুরুটা লিখে দিয়ে ফরম্যাট বাধ্য করা |

## যে ক্রমে প্রয়োগ করবেন

```
১. আগে zero-shot দিয়ে চেষ্টা করুন, নির্দেশনা যতটা সম্ভব স্পষ্ট করে
   ↓ কাজ না করলে
২. few-shot উদাহরণ যোগ করুন — বিশেষত এজ কেসের উদাহরণ
   ↓ ফরম্যাট এলোমেলো হলে
৩. output formatting বেঁধে দিন
   ↓ তবু না মানলে
৪. response prefilling দিয়ে বাধ্য করুন
```

## এই স্তরের সাধারণ ভুল

- **অস্পষ্ট নির্দেশনা** — খারাপ আউটপুটের এক নম্বর কারণ। few-shot যোগ করার আগে নির্দেশনাটা আরেকবার পড়ুন
- **নির্দেশনা আর ডেটা মিশিয়ে ফেলা** — এটাই [Prompt Injection](../05-failure-modes/02-prompt-injection/)-এর দরজা
- **জোর দেওয়ার শব্দ স্তূপ করা** — "you MUST", "খুব জরুরি" — দ্রুত কাজ করা বন্ধ করে দেয়
- **নেতিবাচক নির্দেশনা** — "বেশি লিখো না" নয়, "সর্বোচ্চ ৩ বাক্যে লেখো"
