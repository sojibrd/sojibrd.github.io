# Few-shot Prompting

## সংজ্ঞা
প্রম্পটের ভেতরে ২–৫টা ইনপুট/আউটপুট উদাহরণ দিয়ে মডেলকে প্যাটার্ন শেখানো।

## কখন ব্যবহার করবেন
- আউটপুটের ফরম্যাট নির্দিষ্ট রাখতে হবে
- কাজটার সীমারেখা ভাষায় বোঝানো কঠিন (কোনটা "জরুরি" আর কোনটা না)
- ডোমেইন-নির্দিষ্ট পরিভাষা আছে

## উদাহরণ
```
কাস্টমার সাপোর্ট টিকিটকে ক্যাটাগরিতে ভাগ করো।

টিকিট: "পেমেন্ট কেটে নিয়েছে কিন্তু অর্ডার দেখাচ্ছে না"
ক্যাটাগরি: বিলিং | অগ্রাধিকার: উচ্চ

টিকিট: "অ্যাপের ডার্ক মোড অপশন কোথায়?"
ক্যাটাগরি: সাধারণ জিজ্ঞাসা | অগ্রাধিকার: নিম্ন

টিকিট: "লগইন করতে পারছি না, পাসওয়ার্ড রিসেট মেইল আসছে না"
ক্যাটাগরি: অ্যাকাউন্ট | অগ্রাধিকার: উচ্চ

টিকিট: "ইনভয়েসে আমার কোম্পানির নাম ভুল ছাপা হয়েছে"
ক্যাটাগরি:
```
আউটপুট: `বিলিং | অগ্রাধিকার: মধ্যম`

## মূল নিয়ম
- উদাহরণে **এজ কেস** রাখুন, শুধু সহজ কেস নয়
- সব উদাহরণে **হুবহু একই ফরম্যাট** রাখুন — অসামঞ্জস্য মডেলকে বিভ্রান্ত করে
- ক্লাস ব্যালান্স রাখুন — ৫টা উদাহরণের ৪টাই "উচ্চ" হলে মডেল সবকিছুকে "উচ্চ" বলবে
