# Golden Dataset

## সংজ্ঞা
হাতে যাচাই করা ইনপুট/সঠিক-আউটপুট জোড়ার একটা সেট, যেটাকে সত্যের মানদণ্ড ধরে সব eval চালানো হয়।

## কখন তৈরি করবেন
প্রম্পট লেখার **আগে**। আগে ঠিক করুন সঠিক আউটপুট কেমন হবে, তারপর প্রম্পট লিখুন — উল্টোটা করলে প্রম্পটের পক্ষেই ডেটাসেট বানিয়ে ফেলবেন।

## গঠন
| ধরন | অনুপাত | কেন |
|---|---|---|
| সাধারণ কেস | ~৫০% | মূল কাজটা ঠিক আছে কিনা |
| এজ কেস | ~৩০% | সীমারেখা কোথায় |
| বিরূপ ইনপুট | ~১০% | ভাঙার চেষ্টা |
| অর্থহীন/খালি | ~১০% | ক্র্যাশ হয় কিনা |

## মূল নিয়ম
- প্রতিটা কেসে **`note` লিখুন** — ৩ মাস পর "এই উত্তরটা কেন সঠিক" মনে থাকবে না
- দ্বিমত হলে আগে **মানুষে মানুষে** একমত হোন, তারপর ডেটাসেটে ঢোকান
- ডেটাসেট ভার্সন কন্ট্রোলে রাখুন, প্রম্পটের মতোই — দেখুন [Prompt Versioning](../04-prompt-versioning/)
- ৩০–১০০টা ভালো কেস ১০০০টা যেনতেন কেসের চেয়ে বেশি কাজের
