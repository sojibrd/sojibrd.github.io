# Context Rot

## সংজ্ঞা
কনটেক্সট যত বড় হতে থাকে, আউটপুটের মান তত পড়তে থাকে — এমনকি উইন্ডোর সীমা পেরোনোর অনেক আগেই। জমা হওয়া অপ্রাসঙ্গিক তথ্য, পুরনো সিদ্ধান্ত আর ব্যর্থ চেষ্টা মডেলকে বিভ্রান্ত করে।

## কখন দেখা যায়
- দীর্ঘ এজেন্ট লুপ, যেখানে প্রতিটা টুল-আউটপুট কনটেক্সটে জমছে
- ঘণ্টাব্যাপী চ্যাট সেশন
- একই সমস্যার একাধিক ব্যর্থ চেষ্টা কনটেক্সটে রয়ে গেছে

## লক্ষণ
```
- শুরুতে ভালো উত্তর দিচ্ছিল, ৩০ মিনিট পর এলোমেলো
- আগে বাতিল করা সমাধান আবার প্রস্তাব করছে
- আগে দেওয়া নির্দেশনা ভুলে যাচ্ছে
- একই ভুল বারবার করছে
```

## প্রতিকার

> নিচের `summarize_tool_output`, `token_count`, `compact`, `run_subtask` — এগুলো কোনো লাইব্রেরি ফাংশন নয়, আপনার নিজের লিখতে হবে। কাঠামোটা দেখানোই উদ্দেশ্য।

```python
# ১ — টুল-আউটপুট ছেঁকে নিন, কাঁচা ফেলবেন না
observation = summarize_tool_output(raw_result, max_chars=500)

# ২ — নির্দিষ্ট সীমার পর হিস্টরি সংকুচিত করুন
if token_count(history) > 40_000:
    history = compact(history)      # সিদ্ধান্ত ও তথ্য রাখুন, ব্যর্থ চেষ্টা ফেলে দিন

# ৩ — নতুন সাব-টাস্ক আলাদা পরিষ্কার কনটেক্সটে চালান
result = run_subtask(task, context=[SYSTEM, relevant_facts_only])
```

## মূল নিয়ম
- **নতুন সেশন শুরু করাই প্রায়ই সবচেয়ে ভালো সমাধান** — দরকারি সিদ্ধান্তগুলো সামারি করে নতুন কনটেক্সটে নিয়ে যান
- ব্যর্থ চেষ্টা কনটেক্সটে রাখবেন না, শুধু "এই পথটা কাজ করেনি, কারণ X" — এইটুকু রাখুন
- বড় কাজ ভাগ করে আলাদা কনটেক্সটে চালান, দেখুন [Prompt Chaining](../../03-system-patterns/01-prompt-chaining/)
