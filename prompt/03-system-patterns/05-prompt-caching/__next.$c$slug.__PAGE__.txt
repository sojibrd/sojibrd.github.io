## কখন ব্যবহার করবেন

- একই ডকুমেন্ট নিয়ে একাধিক প্রশ্ন
- মাল্টি-টার্ন কথোপকথন

## মূল নিয়ম
- ক্যাশ **প্রিফিক্স-ভিত্তিক** — শুরুর দিকে একটা অক্ষর বদলালেও পুরো ক্যাশ ভেঙে যায়
- তাই বদলানো জিনিস (তারিখ, ইউজারের নাম, র‍্যান্ডম আইডি) কখনো ক্যাশ ব্লকের ভেতরে রাখবেন না
- ক্যাশ লেখার খরচ সাধারণ ইনপুটের চেয়ে বেশি — একবারই ব্যবহার হবে এমন প্রম্পট ক্যাশ করে লাভ নেই
- ক্যাশের একটা TTL থাকে; সেটা পেরোলে আবার নতুন করে তৈরি হয়
- কনটেক্সটের ক্রম ঠিক রাখলে ক্যাশ এমনিতেই কাজ করে, দেখুন [Context Engineering](../04-context-engineering/)6:Tbe4,# Context Engineering

## সংজ্ঞা
কনটেক্সট উইন্ডোতে কী ঢুকবে, কী ঢুকবে না, আর কোন ক্রমে ঢুকবে — তার পুরো ব্যবস্থাপনা। প্রম্পট ইঞ্জিনিয়ারিং একটা প্রম্পট নিয়ে ভাবে; কনটেক্সট ইঞ্জিনিয়ারিং পুরো উইন্ডোটা নিয়ে ভাবে।

## কখন ভাবতে হবে
- দীর্ঘ কথোপকথন বা এজেন্ট লুপ, যেখানে হিস্টরি বাড়তেই থাকে
- অনেক ডকুমেন্ট বা টুল-আউটপুট জমা হচ্ছে
- খরচ বা লেটেন্সি বাড়ছে, আর মান পড়ছে

## কনটেক্সটের ক্রম
```
১. System prompt          → স্থিতিশীল, ক্যাশযোগ্য
২. টুলের সংজ্ঞা            → স্থিতিশীল, ক্যাশযোগ্য
৩. রেফারেন্স ডকুমেন্ট      → আধা-স্থিতিশীল, ক্যাশযোগ্য
৪. কথোপকথনের হিস্টরি      → বাড়তে থাকে
৫. এই মুহূর্তের প্রশ্ন      → সবার শেষে
```
স্থিতিশীল জিনিস উপরে রাখলে [Prompt Caching](../05-prompt-caching/) কাজ করে।

## উদাহরণ — হিস্টরি ছাঁটাই
```python
def build_context(history, max_turns=10):
    if len(history) <= max_turns:
        return history

    # পুরনো অংশ সামারি করে একটা মেসেজে নামিয়ে আনুন
    old, recent = history[:-max_turns], history[-max_turns:]
    summary = ask("এই কথোপকথনের সিদ্ধান্ত ও তথ্যগুলো ৫টা বুলেটে লেখো:\n" + fmt(old))

    return [{"role": "user", "content": f"<আগের আলোচনার সারসংক্ষেপ>\n{summary}\n</আগের আলোচনার সারসংক্ষেপ>"}] + recent
```

## সংজ্ঞা
একটা মডেলের আউটপুট আরেকটা মডেল দিয়ে মূল্যায়ন করানো। যেখানে সঠিক উত্তর একটা নয়, সেখানে স্বয়ংক্রিয়ভাবে মান মাপার উপায়।

## কখন ব্যবহার করবেন
- আউটপুট লম্বা লেখা (সামারি, ইমেইল, ব্যাখ্যা) — স্ট্রিং মিলিয়ে যাচাই করা যায় না
- হাজারটা কেস মানুষ দিয়ে রিভিউ করা সম্ভব নয়

কখন **নয়**: আউটপুট যদি নির্দিষ্ট মান হয় (ক্যাটাগরি, সংখ্যা) — তখন সরাসরি মিলিয়ে দেখাই সঠিক ও সস্তা।
