3:T9a1,## সংজ্ঞা
অ্যাসিস্ট্যান্ট টার্নের শুরুটা আপনি নিজে লিখে দেন — মডেল সেখান থেকে বাকিটা লেখে। শুধু API-তে সম্ভব।

## কখন ব্যবহার করবেন
- আউটপুট JSON বা নির্দিষ্ট কাঠামোয় লাগবে, আর পার্সিং ভাঙা চলবে না
- মডেল বারবার ভূমিকা লিখে দিচ্ছে ("এই যে আপনার JSON:")
- উত্তর একটা নির্দিষ্ট ট্যাগ বা শব্দ দিয়ে শুরু হওয়া দরকার

কখন **নয়**: [Extended Thinking](../../02-reasoning-techniques/02-extended-thinking/) চালু থাকলে — তখন prefill সমর্থিত নয়।

## কেন কাজ করে
মডেলকে ফরম্যাট মানতে *অনুরোধ* করার চেয়ে ফরম্যাটের ভেতরে *ঢুকিয়ে দেওয়া* অনেক নির্ভরযোগ্য। ভূমিকা লেখার সুযোগই থাকে না।

## উদাহরণ — JSON বাধ্যতামূলক করা
```python
messages = [
    {"role": "user", "content": "এই রিভিউটার সেন্টিমেন্ট JSON-এ দাও: 'ডেলিভারি দেরি, প্রোডাক্ট ভালো'"},
    {"role": "assistant", "content": "{"}   # ← prefill
]
```
মডেল সরাসরি `"সেন্টিমেন্ট": "মিশ্র", ...}` দিয়ে শুরু করবে।
> মনে রাখবেন: শুরুর `{` আউটপুটে থাকবে না, তাই পার্স করার আগে সেটা জোড়া লাগাতে হবে।

## উদাহরণ — চিন্তার কাঠামো বেঁধে দেওয়া
```python
{"role": "assistant", "content": "<বিশ্লেষণ>\n১."}
```

- prefill-এর শেষে অতিরিক্ত স্পেস বা নিউলাইন রাখবেন না

## সংজ্ঞা
আউটপুটের কাঠামো আগে থেকে বেঁধে দেওয়া — যাতে সেটা প্রোগ্রাম দিয়ে পার্স করা যায়।

## কখন ব্যবহার করবেন
- আউটপুট কোনো প্রোগ্রাম পার্স করবে, মানুষ নয়
- একাধিক আউটপুট পাশাপাশি তুলনা করতে হবে (টেবিল, তালিকা)
- আউটপুট পরের কোনো প্রম্পটের ইনপুট হবে, দেখুন [Prompt Chaining](../../03-system-patterns/01-prompt-chaining/)

কখন **নয়**: স্বাভাবিক কথোপকথনের উত্তরে — কাঠামো চাপালে লেখা যান্ত্রিক হয়ে যায়।

## উদাহরণ — স্কিমা দিয়ে বাঁধা
```
নিচের সিভি থেকে তথ্য বের করে ঠিক এই JSON স্কিমায় দাও।
কোনো ব্যাখ্যা বা ভূমিকা লিখবে না — শুধু JSON।

{
  "নাম": string,
  "মোট_অভিজ্ঞতা_বছর": number,
  "দক্ষতা": string[],
  "সর্বশেষ_প্রতিষ্ঠান": string | null
}

তথ্য না পাওয়া গেলে null দেবে, অনুমান করবে না।

<cv>
{{ সিভির টেক্সট }}
</cv>
```

## উদাহরণ — টেবিল
```
৩টা প্যাকেজ তুলনা করে একটা মার্কডাউন টেবিল দাও।
কলাম: প্যাকেজ | মাসিক খরচ | ইউজার লিমিট | কার জন্য উপযুক্ত
টেবিলের বাইরে কিছু লিখবে না।
```

## মূল নিয়ম
- "কোনো ভূমিকা লিখবে না" — স্পষ্ট করে বলতে হয়, নাহলে মডেল ভদ্রতা করে `এই যে আপনার JSON:` লিখে দেয়
- অজানা মানের জন্য কী করবে (null? খালি স্ট্রিং?) সেটা আগেই বলে দিন
- সবচেয়ে নির্ভরযোগ্য পদ্ধতি হলো এর সাথে **response prefilling** যোগ করা
