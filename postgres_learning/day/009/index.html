Create Composite Indexes for Multi-Column Queries

এই দিনের কাজ · মোট ১০′০/১ (০%)
  • Create Composite Indexes for Multi-Column Queries — নিচের Incorrect SQL পড়ে আগে খাতায় এক লাইনে আন্দাজ: কী ভুল; তারপর গাইডে Correct আর ব্যাখ্যা পড়ুন, বন্ধ করে Correct-টা নিজে লিখুন, আর "কেন" ইংরেজিতে ২–৩ বাক্যে জোরে বলুন

    Incorrect (separate indexes require bitmap scan):

    -- Two separate indexes
create index orders_status_idx on orders (status);
create index orders_created_idx on orders (created_at);

-- Query must combine both indexes (slower)
select * from orders where status = 'pending' and created_at > '2024-01-01';
    ১০′🔁 ঝালাই হবেimpact · HIGHআগে আন্দাজ → Correct আর ব্যাখ্যা
দিন শেষে — নিজেকে যাচাই
আন্দাজ লেখা, Correct বন্ধ করে নিজে লেখা, আর "কেন" ইংরেজিতে জোরে বলা হয়েছে?
