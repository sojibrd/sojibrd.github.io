> **৭৬ দিনে React আর Next.js-এর ৭০টা best practice-এর প্রতিটায় না দেখে কোডটা লিখতে পারা, আর "কেন" ইংরেজিতে নিজের কথায় বলতে পারা — ঝালাইসহ।**

এটা শূন্য থেকে Next.js শেখার সাইট নয়। কোড চালু আছে; ইন্টারভিউ জিজ্ঞেস করে "কেন" — AI ছাড়া, নিজের কথায়। প্রতিটা দিন একটা rule ধরে সেই "কেন"-টা মুখে আনার অনুশীলন — পড়ে নয়, লিখে আর বলে। 🧠 (Feynman technique · Active vs Passive learning)

## সত্যের উৎস

এই সাইট React বা Next.js নিয়ে নিজের কোনো rule যোগ করে না — প্রতিটা দিনের কোড আর ব্যাখ্যা rule-এর ফাইল থেকেই।

1. `guide/` — `vercel-react-best-practices` skill-এর ৭০টা rule ফাইল, হুবহু ইংরেজিতে। লেখক আর লাইসেন্স `guide/README.md`-এ; সেকশনের নাম আর ক্রম `guide/_sections.md`-এ।
2. `docs/` — এই plan: নিয়ম আর ৬টা ব্লক।
3. ⚑ দিনের প্রশ্ন — প্রথম তিনটা `brainstorming/application-to-offer.md`-এর ইন্টারভিউ-বিষয় থেকে (দ্বিতীয় আর তৃতীয়টার শব্দ `switch_in_6_month_local_company/docs/05-technical.md`-এর দিন ১৩৩ আর ১৩৬-এর), চতুর্থটা ঐ ফাইলের দিন ১৩৭-এর। শেষ দুই ব্লকের জন্য কোথাও আলাদা প্রশ্ন লেখা নেই, তাই ওখানে ব্লকের rule-ই প্রশ্ন।

## উৎসটা কী, কী নয়

- **React আর Next.js মিলিয়ে।** সেকশনের নাম ধরে ভাগ করলে তিনটা সেকশন (`async-`, `bundle-`, `server-` — ২২টা rule) Next.js আর server-ঘেঁষা; বাকি পাঁচটা (৪৮টা) React আর সাধারণ JavaScript-এর।
- **৬টা rule-এ Incorrect কোড নেই** — শুধু বর্ণনা আর উদাহরণ: `bundle-conditional`, `bundle-preload`, `rendering-activity`, `rendering-content-visibility`, `rendering-resource-hints`, `server-cache-lru`। ওগুলোয় কাজ ভুল ঠিক করা নয়, একটা উদাহরণ লেখা।
- **rule-গুলো Next.js-এর কোনো নির্দিষ্ট version-এর সাথে বাঁধা নয়।** নিচের তালিকাটা তাই আলাদা করে মেলানো।

### Next.js 16-এর সাথে চারটা অমিল

২০২৬-১০-১১-এ শুধু সেই rule-গুলো মেলানো হয়েছে যেগুলো `next/…` থেকে import করে বা Next.js-এর নিজস্ব সেটিং ধরে — Next.js 16.3.5-এর package-এর সাথে আসা ডকের (`node_modules/next/dist/docs/01-app/`) সাথে। rule ফাইল বদলানো হয়নি; অমিলগুলো এখানে, যাতে ঐ দিনে Correct-টা হুবহু মুখস্থ না হয়। ঐ চার দিনে একই কথা একটা **সতর্কতা** হিসেবেও আসে — কাজে টিক দিলে দিনের কার্ডে, আর গাইডের পাতায় Correct-এর ভাঁজের ভেতরে। Correct খোলার আগে দেখায় না, কারণ তাতে উত্তরটাই বলে দেওয়া হয়।

| দিন | rule | rule যা দেখায় | Next.js 16-এর ডক যা বলে |
|---|---|---|---|
| ০৩৫ | `rendering-script-defer-async` | শেষের নোটে `strategy="beforeInteractive"` সহ `<Script>` একটা `Page`-এর ভেতরে | `beforeInteractive` script root layout-এ রাখতে হয় (`03-api-reference/02-components/script.md`) |
| ০৪২ | `bundle-defer-third-party` | Correct-এ `RootLayout`-এ `dynamic(…, { ssr: false })`, ফাইলে `'use client'` নেই | Server Component-এ `ssr: false` চলে না, error আসে; Client Component-এ সরাতে হয় (`02-guides/lazy-loading.md`) |
| ০৪৩ | `bundle-dynamic-imports` | Correct-এ `{ ssr: false }`, ফাইলটা Client Component কিনা দেখানো নেই | একই — শুধু Client Component-এ চলে |
| ০৪৭ | `server-auth-actions` | "middleware"-এর উপর ভরসা না করতে বলে | `middleware` file convention Next.js 16-এ deprecated, নতুন নাম `proxy` (`03-api-reference/03-file-conventions/proxy.md`) |

একই মেলানোয় যা মিলেছে: `experimental.optimizePackageImports` (দিন ০৪০), `after()` আর await করা `headers()` / `cookies()` (দিন ০৫৬), `next/og`-এর `ImageResponse` (দিন ০৫১)। বাকি rule-গুলো — React-এর নিজের API আর সাধারণ JavaScript — কোনো version-এর সাথে মেলানো হয়নি।
